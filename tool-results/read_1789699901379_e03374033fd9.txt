    21→## Architecture Decisions
    22→
    23→- Single visible route `/` (SPA view switching via zustand) — sandbox constraint "user can only see /"
    24→- All backend via API routes (no server actions) — per instructions
    25→- Custom auth instead of NextAuth v4 (v4 compat risk on Next 16): httpOnly cookie `vendora_session`, HMAC-signed `userId.expiry.sig`, scrypt password hashing
    26→- Product images stored as JSON string array in Prisma (SQLite lists not supported)
    27→- Currency USD, formatted via Intl.NumberFormat
    28→- Cart in zustand + localStorage persist; checkout requires login
    29→- Demo accounts: demo@vendora.com / demo1234 (buyer), seller1..5@vendora.com / seller1234 (sellers)
